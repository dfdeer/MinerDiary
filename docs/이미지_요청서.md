# 광부일기 이미지 요청서 (ChatGPT 이미지 생성용)

지금 게임은 아니마룬 에셋을 빌려 쓰고, 맞는 그림이 없는 것(광부, 주민, 성벽, 밭, 소품)은 코드로 그린 단순한 그림이라 서로 그림체가 안 맞음. 이 문서의 블록대로 받으면 한 가지 그림체로 통일할 수 있음.

## 쓰는 방법

1. **블록 하나 = 메시지 하나 = 이미지 한 장.** 코드 상자 안을 통째로 복사해서 보냄.
2. 블록마다 공통 규칙이 들어 있어서 새 채팅방에서 이어 해도 됨.
3. **그림체 고정:** 처음 받은 것 중 마음에 든 이미지를 다음 블록부터 같이 첨부하고 맨 위에 한 줄을 붙임.
   `첨부한 그림의 그림체만 참고해줘 (크기와 자세는 따라 하지 말 것).`
4. 배경이 투명하게 안 나오면 이어서 보냄.
   `이 이미지에서 백그라운드를 제거해줘. 모든 포그라운드 피사체는 변경 없이 온전히 유지하고, 가장자리는 깔끔하고 매끄럽게 처리해줘. 백그라운드는 투명하게 만들어줘.`
5. 받은 이미지는 이 대화에 올리거나 저장소 `assets/incoming/`에 넣으면 됨. 한 장에 여러 개가 든 시트는 제가 칸별로 잘라서 이름을 붙임.
6. 급한 순서는 블록 1 → 2 → 3 → 4. 나머지는 받는 대로 하나씩 넣어도 됨.

## 꼭 지킬 점 (모든 블록 공통, 검수할 때도 이것만 확인)

| 항목 | 기준 |
|---|---|
| 시점 | 쿼터뷰(아이소메트릭). 바닥 한 칸은 가로:세로 2:1 마름모. 건물은 왼쪽 앞면과 오른쪽 앞면, 지붕이 함께 보임 |
| 빛 | 왼쪽 위에서. 그림자는 오른쪽 아래로 짧게 |
| 바닥 | 건물과 물건 밑에 풀밭 받침이나 둥근 섬을 그리지 말 것 (게임 바닥 위에 그대로 올림). 바닥에 닿는 옅은 그림자만 |
| 배경 | 진짜 투명. 글자, 숫자, 테두리, 이름표 금지 |
| 문 방향 | 건물 문은 **왼쪽 앞면**에 |

## 블록 1. 건물 7개 (복구된 모습)

```text
[그림체] 아늑한 판타지 마을 생활 게임. 쿼터뷰(아이소메트릭, 바닥 한 칸이 가로:세로 2:1 마름모) 건물 그림. 부드러운 손그림 느낌, 또렷하지만 너무 굵지 않은 외곽선, 따뜻한 색, 단순한 셀 명암. 빛은 왼쪽 위에서.
모든 건물은 같은 그림체, 같은 시점, 같은 빛 방향. 왼쪽 앞면과 오른쪽 앞면, 지붕이 함께 보이고 문은 왼쪽 앞면에 있음.
[캔버스] 2048×2048 PNG, 배경은 진짜 투명(알파 채널). 글자, 숫자, 테두리, 이름표 금지.
[중요] 건물 밑에 풀밭 받침, 둥근 섬, 바닥 타일을 그리지 말 것. 건물만, 바닥에 닿는 옅은 그림자만.
[배치] 보이지 않는 가로 3칸 × 세로 3줄. 아래 순서대로 왼쪽→오른쪽, 위→아래. 한 칸에 하나씩 가운데에, 칸의 85% 크기. 8, 9번 칸은 비움.
[건물 목록]
1. 낡은 오두막 — 작은 나무 집, 빨간 박공지붕, 굴뚝, 창가 꽃 상자 (바닥 2×2칸)
2. 대장간 — 회색 돌벽, 높은 벽돌 굴뚝, 불빛이 새는 화덕 입구, 문 옆 모루와 물통 (바닥 3×3칸)
3. 식당 — 크림색 벽, 빨간 줄무늬 차양, 문 옆 작은 식탁, 굴뚝 연기 (바닥 3×3칸)
4. 세공소 — 연보라 벽, 보라 뾰족 지붕, 큰 유리창, 지붕 꼭대기에 푸른 보석 장식 (바닥 2×2칸)
5. 시장 — 나무 바닥 위 빨강, 청록, 노랑 천막 가판대 세 개, 과일과 나무 상자 (바닥 가로 4×세로 3칸, 옆으로 긴 모양)
6. 박물관 — 낮은 계단 위 흰 기둥과 삼각 박공이 있는 작은 석조 건물 (바닥 4×4칸)
7. 광산 입구 — 이끼 낀 바위 언덕에 나무틀 굴 입구, 입구 옆 등불, 레일과 광석 수레, 위에 도르래 망루 (바닥 3×3칸)
```

파일 이름: `b_house`, `b_smithy`, `b_kitchen`, `b_jewel`, `b_market`, `b_museum`, `b_mine`
